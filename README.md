# Noughts & Crosses

A tic-tac-toe game in a single HTML file. You can play against the computer on Easy, Medium or Unbeatable, or play with a friend on the same screen.

**Play it:** https://tanaysaveshere.github.io/tic-tac-toe/

To run it locally, open `index.html` in any browser. Keys 1–9 play a square, and N starts a new round after a game ends.
